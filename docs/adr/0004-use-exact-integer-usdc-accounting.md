# Use exact integer USDC accounting

All monetary values use native USDC's six-decimal integer units and basis-point rates; no contract, quote, or accounting path uses floating-point arithmetic. The contract computes the Lucky Amount, Maximum Price, and Final Price itself from the Reference Price and the immutable Game Version, and the Web App and Agent display the contract's quote rather than their own arithmetic. Each Final Price is rounded up to the nearest micro-USDC and never exceeds the Maximum Price, and each Refund is the exact difference between the Maximum Price and the Final Price, so rounding always favours the reserve by less than one micro-USDC and every Refund stays within the amount locked for it. Game Version validation checks the exact probability mass and the exact expected value.
